[신혜진 지원자 PDF 포트폴리오 파일 첨부 안내]
=====================================================

채용 담당자에게 다운로드받게 할 실제 PDF 포트폴리오 파일이 있다면:

1. 좌측 파일 탐색기(File Explorer)에서 'public' 폴더 아래에
   본인의 PDF 파일을 업로드하거나 생성해 주세요.

2. 파일명을 'portfolio.pdf' 또는 '신혜진_포트폴리오.pdf'로 저장하시면
   웹사이트의 'PDF 포트폴리오 다운로드' 버튼 클릭 시
   해당 실제 PDF 파일이 바로 다운로드됩니다!
